# Code of conduct

## Expectations

Keep discussions respectful, direct and focused on the work. Explain technical
criticism, accept corrections, and account for differences in experience and
language. Disagreement about an implementation is welcome; personal attacks,
harassment, discrimination and deliberate disruption are not.

Do not publish someone else's private information or credentials. Use synthetic
data in code examples, issues and test reports.

## Scope and enforcement

These expectations apply to issues, pull requests, discussions, review comments
and other participation representing this project. Maintainers may edit or
remove inappropriate material and restrict participation when necessary.

For a conduct concern, request a private contact channel from
[the maintainer](https://github.com/NullSablex) without posting private details.
For a security vulnerability, follow [SECURITY.md](SECURITY.md).
